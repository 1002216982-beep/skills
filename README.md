# דמות הבוגר – כלי רפלקטיבי למיפוי מצב קיים

כלי דיגיטלי שבו הנהלת בית הספר עונה על שאלון מובנה סביב מודל **"המצפן ההוליסטי"**
(תפיסת החטיבה העליונה המתחדשת), ובסופו מקבלת **דשבורד ויזואלי** של המצב הקיים.

## שימוש מהיר

פותחים את `index.html` בדאבל-קליק – זהו קובץ יחיד עצמאי, ללא צורך בשרת, התקנה או חיבור לאינטרנט.

- מסך פתיחה: הסבר על הכלי, תרשים המצפן ההוליסטי, ושדות (לא חובה) לשם בית הספר ולשם הממלא/ת.
- מילוי: שאלה אחת בכל מסך – 53 שאלות סולם (1–4), 14 פריטי "סל תשתיות מערכתיות" (קיים/לא קיים) ו‑5 שאלות פתוחות. פס התקדמות, ניווט קדימה/אחורה.
- **שמירה אוטומטית**: התשובות נשמרות בדפדפן (localStorage) – אפשר לסגור ולהמשיך מאותה נקודה.
- בסיום: אפקט קונפטי 🎉 ומעבר לדשבורד – ציון כללי, גרף רדאר של 5 המעגלים, גרפי עמודות לפי נושאים, צ'קליסט תשתיות והתשובות הפתוחות.
- כפתורי פעולה בדשבורד: **יצוא ל‑PDF/הדפסה** · **הורדת CSV** · **שליחה ל‑Google Sheet**.

## חיבור ל‑Google Sheet

1. צרו Google Sheet חדש (למשל "מיפוי מצב קיים – תשובות").
2. בתפריט: **Extensions ← Apps Script**.
3. מחקו את הקוד הקיים והדביקו את תוכן הקובץ `google-apps-script.gs`. שמרו.
4. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
5. אשרו את ההרשאות והעתיקו את כתובת ה‑**Web app URL**.
6. פתחו את `index.html` בעורך טקסט, אתרו את השורה:
   ```js
   const SHEET_ENDPOINT_URL = "";
   ```
   והדביקו את הכתובת בין המרכאות. שמרו.

מעתה, לחיצה על "שליחה ל‑Google Sheet" תוסיף שורה חדשה לגיליון (שורת הכותרות נכתבת אוטומטית בפעם הראשונה).
אם הכתובת ריקה או שהשליחה נכשלת – הכלי מוריד אוטומטית קובץ CSV מקומי במקום.

## הטמעת לוגואים

בראש מסך הפתיחה מוצגת שורת לוגואים (משרד החינוך · אגף א' חינוך על יסודי · משרד הבריאות · הג'וינט),
ומתחתיה, במרכז – הלוגו של בית ספר עולם.
לוגו שאין לו תמונה מוטמעת מוצג כתג טקסט. כדי להטמיע תמונה:

1. המירו את קובץ ה‑PNG למחרוזת base64 (למשל באתר base64-image.de, או בטרמינל: `base64 -i logo.png`).
2. ב‑`index.html`, אתרו את `const LOGOS_TOP = [...]` (שורת הלוגואים) ואת `const LOGO_CENTER` (בית ספר עולם), והדביקו את המחרוזת בשדה `b64` של הארגון המתאים, בצורה:
   ```js
   {name:"משרד החינוך", b64:"data:image/png;base64,iVBORw0K..."},
   ```
